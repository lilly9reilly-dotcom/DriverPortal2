# تطبيق المعتمد — الناقلات النموذجية

تطبيق ويب (متصفح أولاً) لعرض وصولات وأرباح كل **معتمد** من قاعدته `DB_*`.
المعتمدون أفراد/جهات معتمدة — **ليست شركات**. الشركات (يونيغاز، ارض الهادي، …) لها تصنيف منفصل.

## تشغيل المعاينة
```bash
./start.sh
# http://127.0.0.1:8765/
```

## دخول تجريبي — معتمدون
| المعتمد | الكود |
|---|---|
| سجاد صويره | `C1587` |
| ابراهيم | `C3137` |
| رواد ريادة | `C2235` |
| قيصر وارد | `C2968` |
| قيصر شمري | `C2058` |

شركات (ليست معتمدين): يونيغاز `C2221` · ارض الهادي `C1220` · شركة `C2297`

## الصفحات
1. الرئيسية — المتبقي والإحصاءات + تسجيل استلام محلي
2. نقلاتي — وصولات مع حالة/تصفية
3. حسابي — استحقاق/مستلم/متبقي + حركات
4. كشوفي — كشف المحطات فقط
5. تقارير — رسم بياني + سيارات + CSV
6. الإعدادات — وسائل الاستلام + تسوية الحساب

## الربط الحي لاحقاً
في `config.js`:
```js
mode: "live",
apiUrl: "https://script.google.com/macros/s/XXX/exec",
allowLiveWrite: false
```
Actions المدعومة في Apps Script: `clientLogin`, `clientGetState` (قراءة أولاً).

## الأمان
- لا كتابة تجريبية على الإنتاج بشكل افتراضي
- عزل المعتمد حسب الكود/`DB_*`
- لا يلمس مسارات السائق (login/gps/trip)

## وسائل الاستلام وتسوية الحسابات
1. من تبويب **الإعدادات** أضف: زين كاش / ماستركارد / بطاقة مصرفية / حساب مصرفي
2. افتح معاينة الإدارة المحلية: `admin-settlements.html`
3. أرسل مبلغاً للمعتمد → يظهر إشعار في تطبيق المعتمد
4. المعتمد يؤكد الاستلام من **الإعدادات → تسوية حسابي** → يصل إشعار للإدارة
