# بوابة العميل (متصفح)

تطبيق ويب لمعاينة وصولات وأرباح كل عميل من قاعدته الخاصة `DB_*`.

## التشغيل محليًا

من جذر المشروع:

```bash
cd client-web
python3 -m http.server 8765 --bind 127.0.0.1
```

ثم افتح في المتصفح:

`http://127.0.0.1:8765/`

> لا تفتح `index.html` مباشرة كملف (`file://`) لأن المتصفح يمنع تحميل ملفات JSON عبر `fetch`.

## دخول تجريبي (يونيغاز)

- العميل: **شركة يونيغاز**
- رمز الدخول: **C2221**
- السيارات: 22219، 22084، 22076، 22339

رموز باقي العملاء تظهر تحت حقل الدخول بعد اختيار الاسم.

## الأقسام

1. **الرئيسية** — إحصاءات الكمية والمبلغ حسب الشهر/الفترة/النوع
2. **الوصولات** — جدول مفصل مع بحث
3. **سياراتي** — سيارات العميل وعدد الوصولات لكل سيارة
4. **عن القاعدة** — شرح قاعدة `DB_*`

## ملاحظة

هذه نسخة متصفح للمعاينة ببيانات تجريبية من التوزيع التاريخي. لاحقًا تُربط بـ Apps Script الحي ثم تُحوَّل لتطبيق موبايل.
