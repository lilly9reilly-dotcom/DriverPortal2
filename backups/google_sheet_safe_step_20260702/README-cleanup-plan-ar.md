## تجهيز عزل GPS في التطبيق

تم تجهيز الكود بحيث تمر طلبات GPS عبر إعداد مستقل:

- `GoogleSheetConfig.GPS_EXEC_ENDPOINT`
- `GoogleSheetConfig.gpsExecUrl(...)`

حاليًا هذا الإعداد يشير إلى نفس Apps Script القديم، لذلك لا يتغير سلوك التطبيق ولا ينكسر النظام.

عند إنشاء ملف/Apps Script منفصل للـ GPS لاحقًا، نغير رابط `GPS_EXEC_ENDPOINT` فقط، وتبقى روابط الحسابات كما هي.
