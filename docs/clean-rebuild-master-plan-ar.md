# خطة إعادة البناء النظيفة الشاملة (Clean Rebuild)

تاريخ الخطة: 2026-07-19

## الهدف
- بدء نظام جديد بالكامل بدون ترقـيع البيانات القديمة.
- الحفاظ على آليات الحماية المذكورة في النظام السابق.
- فصل نظام التتبع (Tracking) عن نظام التشغيل الأساسي (Core) بشكل كامل.

## ما تم تجهيزه تقنيًا
تم إضافة Endpoint جديد داخل الباكند:
- action = resetAllDataWithArchive

هذه العملية تقوم بـ:
1. إنشاء نسخة احتياطية كاملة تلقائيًا قبل أي حذف.
2. أرشفة كل شيتات الأشهر المصدرية (yyyy_MM و F_yyyy_MM) باسم ARCH_...
3. حذف الشيتات المولدة (TPL_ / STMT_)
4. حذف الشيتات الفرعية للتوجيه (مح_ / مع_)
5. مسح بيانات الشيتات التشغيلية مع إبقاء الهيدر (GPS/alerts/issues/maintenance...)
6. الحفاظ على شيتات الحماية وعدم المساس بها:
   - CompanyActivationCodes
   - CompanyActivationAudit
   - AuthorizedDrivers وأسماؤها البديلة
7. إنشاء شيتين نظيفين للشهر الحالي:
   - yyyy_MM
   - F_yyyy_MM

## سياسات الأمان أثناء الحذف
- لا يوجد تنفيذ فعلي بدون رمز تأكيد إلزامي:
  - confirmToken = RESET_ALL_CONFIRMED
- يمكن تنفيذ معاينة بدون أي حذف:
  - dryRun = true
- الوضع الأمني الصارم يبقى مفعّلًا:
  - SECURITY_SCOPE_STRICT_BLOCK_UNSCOPED = true

## خطوات التنفيذ الفعلي (مرحلة 0)

### 1) فحص الصحة
نفذ طلب API:
- action=systemHealthCheck

### 2) معاينة إعادة الضبط بدون حذف
نفذ طلب API:
- action=resetAllDataWithArchive
- dryRun=true

### 3) تنفيذ إعادة الضبط الفعلية
نفذ طلب API:
- action=resetAllDataWithArchive
- confirmToken=RESET_ALL_CONFIRMED
- dryRun=false

### 4) حفظ بيانات النسخة الاحتياطية
من الاستجابة، احتفظ بالحقول:
- backupFileId
- backupName
- backupUrl

## مراحل التنفيذ بعد البداية النظيفة

## المرحلة 1: فصل التتبع عن النظام
- إنشاء مشروع Tracking مستقل (API + Dashboard + Data Store).
- منع أي كتابة GPS داخل Core Sheets.
- الربط بين النظامين عبر API Contracts فقط.

## المرحلة 2: إعادة بناء Core
- اعتماد مخطط بيانات جديد موحّد.
- تفعيل قواعد الدقة والتحقق قبل الحفظ.
- تقارير تشغيلية ومالية من مصدر الحقيقة فقط.

## المرحلة 3: تعزيز الحماية
- RBAC دقيق لكل لوحة.
- تفعيل تدقيق شامل Audit Logs.
- فرض التحقق من companyId + activationCode على كل العمليات الحساسة.

## المرحلة 4: الاختبارات والانتقال
- مقارنة نتائج القديم والجديد لفترة انتقال.
- تشغيل تدريجي لكل برنامج (Android/iOS/Desktop/Admin).
- إيقاف المسارات القديمة بعد التحقق.

## ملاحظات مهمة
- هذه الخطة تعتمد على حذف تشغيلي آمن مع أرشفة كاملة (وليس حذفًا نهائيًا غير قابل للاسترجاع).
- يمكن استرجاع أي شهر قديم من أرشيف ARCH_ عند الحاجة.
- الحماية القديمة محفوظة ومفعلة ضمن النسخة الجديدة.
