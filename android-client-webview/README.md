# غلاف أندرويد — بوابة العميل (WebView)

هذا مجلد **تهيئة فقط** لتحويل `client-web/` إلى تطبيق موبايل لاحقاً.

## القواعد
- لا رفع رقم نسخة المتجر إلا بطلب صريح
- المصدر الحقيقي للواجهة: `/client-web`
- لا يلمس تطبيق السائق ولا تطبيق الشركة

## التشغيل لاحقاً
1. انسخ محتويات `client-web/` إلى `assets/client-web/`
2. اضبط `portal_url` على رابط Web App بعد النشر الآمن
3. ابنِ APK من وحدة أندرويد مستقلة (أو نكهة `client`) بعد اعتماد الواجهة في المتصفح

## الحالة الحالية
الخطوة [8] جاهزة كهيكل. التنفيذ الكامل للبناء بعد ثبات المتصفح + `clasp login`.
